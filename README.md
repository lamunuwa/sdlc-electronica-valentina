# Desarrollo de Software Backend con IA (EDSIA)

Este repositorio contiene el desarrollo de las prácticas y proyectos de código para el programa **EDSIA**. El objetivo central del repositorio es documentar el proceso de aprendizaje y ejecución entre el diseño de hardware/sistemas embebidos y la ingeniería de software moderna, integrando principios fundamentales del software (SOLID), arquitecturas web robustas (FastAPI), contenedores (Docker) y flujos de trabajo basados en Inteligencia Artificial.

---

## Flujo de Trabajo

Cuando trabajo en un repositorio no suelo subir todo a la branch "main", prefiero trabajar en diferentes branches con la finalidad de poder equivocarme, cambiar librerías, configuraciones, etc., y siempre tener "main" como mi última versión estable. Por lo que este repositorio no recibirá código de desarrollo directamente en la rama principal. En su lugar, se implementará una arquitectura basada en **GitHub Flow**:

```text
  ┌───────────────── (Rama Temporal: semanaX) ─────────────────┐
  │                                                            ▼
[ main ] ──────────────────────────────────────────────────► [ PR / Merge ] ──► [ main (Estable) ]
```
